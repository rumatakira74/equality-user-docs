# Glossaire (RU → FR) — minimum pour l'utilisateur

Terminologie fixe pour le miroir `fr-translation/` de ce dépôt. Les termes suivent la localisation de l'application (`app/lib/l10n`, `app_fr.arb` du dépôt principal) et, lorsque la localisation ne contient pas le terme, les textes anglais établis de la plateforme (`docs/KNOWLEDGE-ENG-1..5.md`, `README-ENG.md`) ; aucun synonyme n'est inventé. Le glossaire complet pour développeurs se trouve dans `equality-programming-docs` ; ce fichier est le sous-ensemble réduit, orienté utilisateur, appliqué dans ces traductions.

Les identifiants de code, les noms de champs et les étiquettes (`protocolVersion`, `Eq-<hash8>`, `K = 3`, PIN, QR) ne se traduisent jamais.
