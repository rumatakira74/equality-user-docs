# 5. 常见问题 · 词汇表

## FAQ

**需要互联网吗？**
日常操作——需要，至少有间歇性的连接。蓝牙可以把已签名的交易直接传给收款人，但在发布并经网络确认之前付款并未成立。

**我在网络里没有熟人。怎么激活？**
通过社区的公共渠道：新人在那里寻找担保人。担保人以有限的名额和自己的奖励负责，把担保分给任何人对他们并不划算。担保可以当面通过二维码或蓝牙办理。

**我丢了手机。单位怎么办？**
密钥不可导出，但社会恢复可以运作：守护人（个人 2/3 或公共 3/5）确认向新手机的迁移；14 天后账龄、历史、担保和资金转移过去。没有指定的守护人——只能重新注册，旧钱包上的资金丢失。

**可以更换守护人吗？**
可以。如果守护人失踪、去世或退出网络，请改选他：新守护人亲自签署变更哈希，变更以显式输入 PIN 发布，48 小时后生效（在此之前可以取消）。上限——钱包存续期内 150 次生效变更。详情——[「守护人变更」](03-operations.md#守护人变更)。

**两个 PIN 都忘了。**
钱包变得不可访问：密钥无法取出，PIN 无法「通过邮件重置」——在没有服务器的系统里不存在这样的渠道。唯一的路——经守护人的迁移。

**有人能伪造我的钱包吗？**
密钥在手机的安全存储区里；只有它能签署操作。没有对已解锁设备的物理访问，伪造不可能。

**如果有人创建几百个钱包（农场）怎么办？**
屏障：每个钱包 3 个担保（名额有限）、硬件认证（模拟器和 root 设备通不过，认证链与注册密钥绑定）、本周期时隙内的计算挑战、转账宽限期、手续费和损耗费。农场经济模型：按每台设备 $120 的基准估价，农场约 3.5 年后才开始盈利（$200 时约 4.5 年），而且只在单位外部价值很高时；同一设备上的多个钱包会降低农场成本——结论的稳健性已用敏感性网格（设备成本 × 每台设备钱包数）验证。安全度量的检验视野不少于 5 年。「一个人——一个钱包」的保证谁也给不了：保护是经济性的。

**为什么余额自己变少了？**
在货币网络中运行着损耗费——免征额度之上的少量月度百分比。它在下次操作时体现；没有单独的扣款交易。

**转账「卡住」了 48 小时。这是被黑了吗？**
不是，这是延迟转账：高于阈值（默认 3000）的金额总是 48 小时后执行，执行前可以取消。

**能在网络内匿名投票吗？**
v1 中——不能：第三方应用的标识符与地址公开关联。匿名投票只能在未来的版本中出现。

**应用提示「单位已失效」。这是什么？**
您在订阅网络（recurring）中：配额绑定到周期，过了下一个周期的边界它就不能再转账。这不是罚款，也不是余额损失——新配额在新周期到来；多余部分最好通过 peer-redeem 交给需要资源的人。

**参与要花钱吗？**
网络不收参与费。平台完全没有运营成本——服务器根本不存在。转账手续费被销毁，谁也拿不到。

## 词汇表

| 术语 | 含义 |
|------|------|
| **钱包** | 成员的账户：地址 + 已签名记录链 + 余额。每台设备一个。 |
| **名录** | 网络所有交易的公开账本；每个节点都保存并校验它。 |
| **创世包（genesis）** | 网络的启动包：参数、清单、种子圈。 |
| **协议版本（`protocolVersion`）** | 网络规则的版本号（当前为 3）。写进每笔交易和每个检查点；应用与网络必须在协议版本上一致——版本不同的构建不被网络接受。 |
| **清单（manifest）** | 网络规则的公开描述；其哈希固定在创世包中。 |
| **种子圈** | 创世包中的首批成员，拥有临时特殊权利；权利自我清算（seed_sunset：100 个活跃钱包或 24 个纪元）。 |
| **担保（`vouch`）** | 在任成员为新人的签名背书。三个担保激活钱包。 |
| **担保名额** | 担保人的有限名额；被担保人完成 3 个发行周期或 90 天后释放。 |
| **发行挑战** | 本周期时隙内可预先算出的计算任务（PoW）；±48 小时窗口每个周期都可用，其状态显示在发行界面；错过在累积窗口（6 个周期）内补偿。 |
| **纪元（epoch）** | 网络时间的区间（默认 24 小时）；检查点设在纪元边界。 |
| **检查点** | 由成员阈值签署的网络状态快照；提供最终性（finality）并保护轻节点（light node）。 |
| **最终性（finality）** | 交易在此之后不可能被回滚的时刻。 |
| **宽限期** | 注册后的周期（默认 14 天），期间转出转账不可用。 |
| **损耗费（demurrage）** | 免征额度之上的月度保管百分比；扣掉的被销毁。 |
| **诱饵** | 胁迫 PIN 打开的模式：逼真的界面加小额余额，没有真实操作。 |
| **守护人** | 被指定在手机丢失时确认迁移的成员。 |
| **迁移** | 经守护人把钱包转移到新设备；延迟 14 天。 |
| **守护人变更** | 经新守护人同意改选个人守护人（最多 3 名）；48 小时窗口，钱包存续期内 150 次生效变更的上限。 |
| **Flagged** | 已证实违规（双签冲突）的公开标记。 |
| **BT 支付** | 通过蓝牙传输已签名的交易；经网络确认后才成为付款。 |
| **网络配置（profile）** | 参数集合：单位、发行、转账、排放、进入等等。 |
| **Eq 哈希（`Eq-<hash8>`）** | 网络的短标签（其标识符的前 8 个字符）；显示在应用名称和入驻流程中——用它核对安装的是正确的网络。 |
| **Recurring（订阅网络）** | 订阅资源网络：每周期相等配额，未使用的在周期边界失效。 |
| **点对点兑换（peer-redeem）** | recurring 网络中成员 → 成员或成员 → 提供方的转账：多余配额流向需要资源的人（当前应用界面尚未实现）。 |
| **配额失效** | 上一周期的单位在下一个周期边界之后不再是可转的；余额和历史同时保留。 |
