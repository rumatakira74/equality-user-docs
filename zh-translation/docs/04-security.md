# 4. 所有者的安全

## PIN 与生物识别：各管什么

| 操作 | 用什么确认 |
|------|------------|
| 登录应用 | 指纹**或** PIN |
| 转账、发行、启动迁移 | **只能显式输入 PIN** |
| 守护人变更（发布、取消） | **只能显式输入 PIN** |
| 操作内部解锁密钥 | PIN 之后的生物识别——只用于「解锁」 |

为什么这样设计：指纹**可以被物理胁迫**——可以强行把别人的手指按在传感器上。PIN 不能。因此每一个可能造成损失的操作都要求 PIN，而且每一张 PIN 输入界面同时是诱饵模式（见下文）的入口。

指纹登录只是解锁界面的便利手段；启用胁迫 PIN 后它被完全停用。

## 胁迫 PIN 与诱饵模式

威胁：有人逼迫您打开应用或转出单位。

在设置时您设定两个 PIN：**普通**和**胁迫**。胁迫 PIN 打开**诱饵模式**：

- 界面看起来完全一样，但显示一个可信的**小额余额**和历史（不能显示零：活跃钱包会定期收到发行，零余额会很可疑）；
- 从诱饵发出的「转账」以可信的「等待确认」或网络错误结束——真实交易不会被发布；
- 真实钱包继续在后台运行；
- 通知不包含金额：应用中没有交易通知；唯一的系统通知是节点的前台服务（foreground）（「信任网络节点正在运行」），没有金额和地址；
- 诱饵中的「守护人变更」会逼真地「执行」，但真实的守护人名单不会被改动。

两个 PIN **无法区分**：相同的开启时间、相同的界面、相同的尝试次数限制。胁迫 PIN 在**任何** PIN 输入界面都生效——转账、发行、更改设置。

**可以隐藏，不能清零：** 余额是网络的公开状态，密钥不会被删除。本地数据库可以用系统自带的手段删除——与网络核对后会恢复。

## 大额延迟转账——第二层保护

高于阈值（默认 3000 单位）的转账经过 **48 小时**才执行；执行前的任何时刻都可以取消。胁迫者得到的是「转账已发送」，而不是单位；您一脱离险境就取消它。延迟是固定的，不能关闭。

## 保护做不到什么（请诚实地阅读）

- **名录是公开的。** 任何您付过款或从其收款的人都知道您的地址；历史是公开的，余额可以从网络状态推导（应用的名录显示地址、状态和账龄；余额——在钱包中和通过检查点的 Merkle 证明显示）。诱饵经得起核对：它的地址在网络上与真实地址不一致。
- **对有准备的攻击者，诱饵没有保证。** 它防的是快速胁迫和抢劫。
- **防被偷走的已解锁手机**靠「每次操作都签名」：仅仅把手机拿在手里，花不出单位。
- **防手机丢失**——靠守护人和迁移（[恢复](03-operations.md#恢复访问)一节）。没有守护人，资金会丢失。
- **知道您 PIN 的窃贼可以在 14 天窗口内取消迁移**——v1 的已知限制：取消权属于旧密钥。缓解手段——公共守护人和重新启动迁移。

## 安全设置清单

1. 首次启动时设定 PIN 和胁迫 PIN。
2. 指定守护人（2/3 个人守护人或 3/5 公共守护人）——立即，在创建钱包时。
3. 填写恢复卡（[「恢复」一节](03-operations.md#恢复卡请提前填写)）：钱包地址、守护人地址、网络名称——记下来并保存在手机之外。迁移数据（nonce、守护人签名）不要交给任何人，也不要公开。
4. 不要把 PIN 告诉任何人；胁迫 PIN 更是如此（不应有人知道它存在）。
5. 记住：在系统中添加新指纹会使密钥失效——这是防调包的保护，但也是您失去访问的风险。
6. 不要为了「以防万一」保存大额资金——货币网络中的损耗费惩罚的正是囤积。
