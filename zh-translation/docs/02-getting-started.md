# 2. 开始使用

> **状态：测试版本。** 应用程序已在封闭测试网络的模拟器上验证。公开构建和应用商店发布——在试点之后。以下所有步骤描述完整的入驻路径。

## 需要准备什么

- 一部带安全硬件密钥库（StrongBox / TEE）并已设置指纹的 Android 智能手机。
- 未设置生物识别的设备不能注册：应用程序会通过系统界面提示设置生物识别。
- 网络里的熟人：激活钱包需要 **3 个**在任成员的**担保**（见下文）。

## 安装

应用程序以 APK 形式分发（关于通过 Google Play 分发的章节——正在法律审查中）。请安装自己网络的 APK 文件：每个网络实例都可以分发内嵌参数的自有构建。网络的 应用以网络名称和 `Eq-<hash8>` 标签签名——安装时请核对标签，以免装成别的网络。应用程序与网络必须在**协议版本**（当前为 3）上一致：版本号写进每一笔交易和每个检查点；版本不同的构建不会被网络接受。

应用程序的界面提供五种语言：俄语、英语、西班牙语、葡萄牙语、中文。

## 创建钱包

1. 应用程序**在手机的安全存储区（Keystore）内部**创建密钥对。私钥不可导出：无法复制、导出或转发——永远不能。
2. 手机通过**硬件认证**：网络验证这是一台启动未被改动、硬件受保护的真实设备，且认证链正是为你的新密钥签发（密钥与证书的绑定——网络每个节点都会亲自校验，无法伪造他人的认证链）。指纹图像不会传送到任何地方。
3. 执行一道计算任务（proof-of-work）——防止大规模自动注册。只需几秒钟。
4. 钱包获得 **registered** 状态——它已经可以接收转账，但发行和发送尚不可用。

一个人 ≈ 一个钱包：从同一设备重复注册是**困难的**——它需要昂贵得多的计算工作（PoW），而且「一台设备——一个钱包」并没有严格的硬件保证。

## 担保：通往激活状态之路

要完整使用，钱包必须成为 **active**。为此需要来自不同活跃成员的 **K = 3 个担保**（`vouch`）。

**谁可以担保：**

- 状态为 `active` 且钱包账龄满 3 个月的成员；
- 拥有空闲担保名额（名额不多：按账龄为 3–5 个）；
- 担保可以当面通过二维码或蓝牙办理。

**担保意味着什么。** 担保人只拿自己的名额和奖励份额冒险，不会损失单位。对诚实的新人，担保人获得被担保人**前 12 次发行的 10%**（从新人自己的发行中支付，不是凭空产生）。如果新人被查出违规——担保人失去奖励。

**如果网络里没有熟人：** 请使用社区的公共渠道，新人在那里寻找担保人。担保人以有限的名额对选择负责——把担保「撒」给任何人对他们并不划算。

## 首次登录与 PIN

在设置时您选择：

- **PIN**——确认危险操作的主要方式；
- 如愿意——**胁迫 PIN**（见[安全](04-security.md)）；
- 登录应用——用指纹或 PIN。

关键安全规则：

- **登录**应用——指纹或 PIN。
- **危险操作**（转账、发行、启动迁移）——**只能显式输入 PIN**。指纹从不用于确认这些操作：手指可以被强行按上，PIN 不能。
- 如果启用了胁迫 PIN，指纹登录会被停用。

在系统中添加新指纹会使**密钥失效**（更安全，但意味着失去访问）——所以请立即指定守护人。

## 守护人：请立即指定

请在**创建钱包时**指定守护人，而不是在手机已经泡水之后：

- **个人守护人**——自选的 2/3 个人；
- 或**公共守护人**——账龄满 12 个月的经过验证的成员；阈值为 3/5（可以组合）。

守护人去世、失踪或退出网络了？守护人可以**稍后改选**——需新守护人同意（48 小时窗口，150 次生效变更的上限）。如何操作——见[「守护人变更」](03-operations.md#守护人变更)一节。不要推迟指定本身：没有守护人就无法恢复。

详情见[恢复](03-operations.md#恢复访问)一节。

并且请立即填写**恢复卡**（见[恢复](03-operations.md#恢复卡请提前填写)）：自己钱包的地址、守护人的地址、网络名称——记下来并保存在手机之外。手机丢失后，这些数据就再也无处可取。应用程序在「恢复卡」界面上以二维码显示这些数据。

## 钱包的状态

| 状态 | 如何获得 | 能做什么 |
|------|----------|----------|
| `registered` | 注册之后（认证 + PoW） | 接收转账 |
| `active` | 3 个担保 | 发行、转账、担保 |
| `expired` | registered 状态 3 年未激活 | 向该地址的转账仍会保留；要发行需要重新注册 |
| `flagged` 标记 | 已证实的违规（双签） | 发行暂停，不能为他人担保 |
