# 2. Начало работы

> **Статус: тестовая версия.** Приложение проверено в закрытой тестовой сети на эмуляторах. Публичная сборка и публикация в магазинах приложений — после пилотов. Все шаги ниже описывают полный путь онбординга.

## Что понадобится

- Android-смартфон с аппаратным защищённым хранилищем ключей (StrongBox / TEE) и настроенным отпечатком пальца.
- Устройство без настроенной биометрии к регистрации не допускается: приложение предложит настроить биометрию через системный экран.
- Знакомые в сети: для активации кошелька нужны **3 поручительства** действующих участников (см. ниже).

## Установка

Приложение распространяется как APK (раздел о распространении через Google Play — на юридической проверке). Установите APK-файл своей сети: каждая сеть-инстанс может распространять собственную сборку с зашитыми параметрами.

## Создание кошелька

1. Приложение создаёт ключевую пару **внутри защищённого хранилища телефона (Keystore)**. Приватный ключ неэкспортируем: его нельзя скопировать, выгрузить или переслать — никогда.
2. Телефон проходит **аппаратную аттестацию**: сеть проверяет, что это настоящее устройство с неизменённой загрузкой и защищённым железом. Образ пальца никуда не передаётся.
3. Выполняется вычислительная задача (proof-of-work) — защита от массовой автоматической регистрации. Это занимает секунды.
4. Кошелёк получает статус **registered** — он уже может принимать переводы, но выпуск и отправка пока недоступны.

В одной сети — один кошелёк на устройство. Повторная регистрация с того же устройства отклоняется.

## Поручительства: путь к активному статусу

Для полноценной работы кошелёк должен стать **active**. Для этого нужны **K = 3 поручительства** (`vouch`) от разных активных участников.

**Кто может поручиться:**

- участник со статусом `active` и возрастом кошелька от 3 месяцев;
- имеющий свободные слоты поручительства (их немного: 3–5 в зависимости от стажа);
- поручительство можно оформить при личной встрече через QR-код или Bluetooth.

**Ч
то означает поручительство.** Поручитель рискует только своим слотом и долей награды, потери единиц ему не грозят. За честного новичка поручитель получает **10% от первых 12 выпусков** поручаемого (выплачивается из выпуска самого новичка, а не из воздуха). Если новичок уличён в нарушении — поручитель теряет награду.

**Если знакомых в сети нет:** пользуйтесь публичными каналами сообщества, где новички находят поручителей. Поручитель отвечает за выбор ограниченным слотом — «раздача» поручительств всем подряд ему невыгодна.

## Первый вход и PIN

При настройке вы выбираете:

- **PIN** — основной способ подтверждения опасных операций;
- при желании — **тревожный PIN** (см. [Безопасность](04-security.md));
- вход в приложение — по отпечатку или PIN.

Ключевые правила безопасности:

- **Вход** в приложение — отпечаток или PIN.
- **Опасные операции** (перевод, выпуск, запуск миграции, смена PIN) — **только явный ввод PIN**. Отпечаток для их подтверждения не используется никогда: палец можно приложить силой, PIN — нет.
- Если включён тревожный PIN, вход по отпечатку отключается.

Добавление нового отпечатка в системе **инвалидирует ключ** (безопаснее, но означает потерю доступа) — поэтому сразу назначайте гардианов.

## Гардианы: назначьте сразу

Назначьте гардианов **при создании кошелька**, а не когда телефон уже утоплен:

- **личные гардианы** — 2 из 3 людей на выбор;
- или **публичные гардианы** — проверенные участники со стажем от 12 месяцев; порог 3 из 5 (можно комбинировать).

Подробно — в разделе [Восстановление](03-operations.md#восстановление-доступа).

И сразу заполните **карточку восстановления** (см. [Восстановление](03-operations.md#карточка-восстановления-заполните-заранее)): адрес своего кошелька, адреса гардианов и название сети — запишите и храните вне телефона. При утрате телефона эти данные будет уже не откуда взять. Приложение показывает их на экране «Карточка восстановления» с QR-кодом.

## Статусы кошелька

| Статус | Как получается | Что можно |
|--------|----------------|-----------|
| `registered` | после регистрации (аттестация + PoW) | принимать переводы |
| `active` | 3 поручительства | выпуск, переводы, поручительства |
| `expired` | 3 года в registered без активации | переводы на адрес сохраняются; для выпуска нужна новая регистрация |
| метка `flagged` | доказанное нарушение (двойная подпись) |
 выпуск приостановлен, поручаться за других нельзя |
