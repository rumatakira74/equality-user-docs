# 5. Вопросы и ответы · Словарь

## FAQ

**Нужен ли интернет?**
Для обычных операций — да, связь хотя бы периодическая. Bluetooth позволяет передать подписанную транзакцию напрямую получателю, но оплата состоится только после публикации и подтверждения сетью.

**У меня нет знакомых в сети. Как активироваться?**
Через публичные каналы сообщества: новички находят поручителей там. Поручитель отвечает ограниченным слотом и наградой, раздавать поручительства всем подряд ему невыгодно. Поручительство можно оформить при личной встрече через QR или Bluetooth.

**Я потерял телефон. Что с единицами?**
Ключ неэкспортируем, но работает социальное восстановление: гардианы (личные 2 из 3 или публичные 3 из 5) подтверждают миграцию на новый телефон; через 14 дней возраст, история и поручительства переносятся. Без назначенных гардианов — только новая регистрация, средства на старом кошельке теряются.

**Я забыл оба PIN.**
Кошелёк становится недоступным: ключ нельзя извлечь, PIN нельзя «сбросить по почте» — таких каналов в системе без серверов нет. Единственный путь — миграция через гардианов.

**Может ли кто-то подделать мой кошелёк?**
Ключ в защищённом хранилище телефона; подписать операцию может только он. Подделка невозможна без физического доступа к разблокированному устройству.

**Что если кто-то создаст сотни кошельков (ферму)?**
Барьеры: 3 поручительства на кошелёк (слоты ограничены), аппаратная аттестация (эмуляторы и рутованные устройства не проходят), вычислительный челлендж в непредсказуемом слоте, мораторий на переводы, комиссия и демередж. Модель фермерской экономики показала: ферма окупается не ранее ~3 лет и только при высокой внешней ценности единицы. Гарантии «один человек — один кошелёк» не даёт никто: защита экономическая.

**Почему остаток уменьшился сам?**
В валютных сетях работает демередж — небольшой ежемесячный процент сверх необлагаемого минимума. Он отражается при следующей операции; отдельной транзакции списания нет.

**Перевод «завис» на 48 часов. Это взл
ом?**
Нет, это отложенный перевод: сумма выше порога (по умолчанию 3000) всегда исполняется через 48 часов, и его можно отменить до исполнения.

**Можно ли голосовать тайно внутри сети?**
В v1 — нет: идентификатор для стороннего приложения публично связан с адресом. Тайные голосования возможны только в будущих версиях.

**Сколько стоит участие?**
Сеть не берёт плату за участие. Операционных расходов у платформы нет вообще — серверов не существует. Комиссия перевода сжигается, а не достается никому.

## Словарь

| Термин | Значение |
|--------|----------|
| **Кошелёк** | Учётная запись участника: адрес + цепочка подписанных записей + баланс. Один на устройство. |
| **Реестр** | Публичный журнал всех транзакций сети; его хранит и проверяет каждый узел. |
| **Genesis** | Пакет запуска сети: параметры, манифест, посевной круг. |
| **Манифест** | Публичное описание правил сети; хеш зафиксирован в genesis. |
| **Посевной круг** | Первые участники из genesis с временными особыми правами; права самоликвидируются (seed_sunset: 100 активных кошельков или 24 эпохи). |
| **Поручительство (vouch)** | Подписанная ручка действующего участника за нового. Три штуки активируют кошелёк. |
| **Слот поручительства** | Ограниченное место поручителя; освобождается через 3 периода выпуска поручаемого или 90 дней. |
| **Челлендж выпуска** | Вычислительная задача (PoW) в случайном слоте периода; окно ±48 ч. |
| **Эпоха** | Интервал сетевого времени (по умолчанию 24 часа); по границам эпох ставятся чекпоинты. |
| **Чекпоинт** | Подписанный порогом участников снимок состояния сети; даёт финальность и защиту лёгких узлов. |
| **Финальность** | Момент, после которого транзакцию невозможно откатить. |
| **Мораторий** | Период после регистрации (7–30 дней), когда исходящие переводы недоступны. |
| **Демередж** | Ежемесячный процент на хранение сверх минимума; списанное сжигается. |
| **Приманка** | Режим, открываемый тревожным PIN: правдоподобный интерфейс с небольшим остатком, реальных операций н
ет. |
| **Гардиан** | Участник, назначенный для подтверждения миграции при утрате телефона. |
| **Миграция** | Перенос кошелька на новое устройство через гардианов; задержка 14 дней. |
| **Flagged** | Публичная метка доказанного нарушения (эквивокации). |
| **BT-платёж** | Передача подписанной транзакции по Bluetooth; оплатой становится только после подтверждения сетью. |
| **Профиль сети** | Набор параметров: единица, выпуск, передача, сток, вход и т.д. |
