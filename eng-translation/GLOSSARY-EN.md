# Glossary (RU → EN) — user-facing minimum

Fixed terminology for the `eng-translation/` mirror of this repository. Terms follow the established English texts of the platform specification (`docs/KNOWLEDGE-ENG-1..5.md`, `README-ENG.md` in `equality-trust-networks`); do not invent synonyms. The full developer glossary lives in `equality-programming-docs/eng-translation/GLOSSARY-EN.md`; this file is the reduced, user-facing subset applied in these translations.

Code identifiers, field names, labels (`protocolVersion`, `Eq-<hash8>`, `K = 3`, PIN, QR) are never translated.
