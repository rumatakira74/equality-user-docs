# Glossario (RU → IT) — il minimo per l'utente

Terminologia fissa per il mirror `it-translation/` di questo repository. I termini seguono la localizzazione dell'app (`app/lib/l10n`, `app_it.arb` del repository principale) e, quando la localizzazione non contiene il termine, i testi inglesi consolidati della piattaforma (`docs/KNOWLEDGE-ENG-1..5.md`, `README-ENG.md`); non si inventano sinonimi. Il glossario completo per gli sviluppatori si trova in `equality-programming-docs`; questo file è il sottoinsieme ridotto, orientato all'utente, applicato in queste traduzioni.

Gli identificatori di codice, i nomi dei campi e le etichette (`protocolVersion`, `Eq-<hash8>`, `K = 3`, PIN, QR) non si traducono mai.
