# 5. よくある質問 · 用語集

## FAQ

**インターネットは必要か？**
通常の操作には — はい、少なくとも周期的な接続が必要です。Bluetooth なら、署名済みトランザクションを受取人に直接渡せますが、支払いが成立するのは公開とネットワークの確認の後です。

**ネットワークに知人がいません。どうやってアクティベートするのですか？**
コミュニティの公共チャネル経由で：新人はそこで保証人を見つけます。保証人は限られた枠と報酬で選択に責任を負います。保証を誰にでもばら撒くことは彼の得になりません。保証は QR または Bluetooth による対面で行えます。

**電話を紛失しました。単位はどうなりますか？**
鍵はエクスポート不可能ですが、ソーシャルリカバリーが機能します：ガーディアン（個人 3 人中 2 人、または公共 5 人中 3 人）が新しい電話へのマイグレーションを確認します。14 日後に、年齢、履歴、保証、資金が移転します。指名されたガーディアンがいなければ — 新規登録のみで、古いウォレットの資金は失われます。

**ガーディアンを交代できますか？**
はい。ガーディアンが行方不明、死亡、またはネットワークを離脱した場合は再選出してください：新しいガーディアンは交代のハッシュに自ら署名し、交代は明示的な PIN 入力付きで公開され、48 時間後に発効します（それまでは取り消せます）。上限 — ウォレットの生存期間中に発効する交代 150 回。詳細は[「ガーディアンの交代」](03-operations.md#ガーディアンの交代)。

**両方の PIN を忘れました。**
ウォレットはアクセス不能になります：鍵は取り出せず、PIN は「郵便でリセット」できません — サーバーなしのシステムにそのようなチャネルはありません。唯一の道 — ガーディアン経由のマイグレーションです。

**誰かが私のウォレットを偽造できますか？**
鍵は電話の保護されたストレージの中にあります。操作に署名できるのは鍵だけです。解錠された端末への物理的アクセスなしに偽造は不可能です。

**誰かが何百ものウォレット（ファーム）を作ったら？**
防壁：ウォレットごとに保証 3 件（枠は限られる）、ハードウェア認証（エミュレータとルート化端末は通過できず、認証チェーンは登録される鍵に紐付く）、現在の周期のスロットでの計算チャレンジ、モラトリアム、手数料とデマレージ。ファーム経済のモデル：端末 1 台あたり $120 の正統評価では、ファームが黒字になるのは早くても約 3.5 年後（$200 なら約 4.5 年後）で、しかも単位の外部価値が高い場合だけです。一台の端末に複数のウォレットがあるとファームは割安になります — 結論の堅牢性は感度グリッド（端末コスト × 端末あたりウォレット数）で検証済みです。セキュリティメトリックの検証地平 — 5 年以上。保証「一人 — 一つのウォレット」を誰も与えません：保護は経済的です。

**残高が勝手に減ったのはなぜ？**
通貨ネットワークではデマレージが働いています — 非課税最低限を超える小さな月次パーセントです。次の操作時に反映されます。別個の引き落としトランザクションはありません。

**送金が 48 時間「固まっています」。ハッキングですか？**
いいえ、遅延送金です：しきい値（デフォルト 3000）を超える金額は必ず 48 時間後に実行され、実行前なら取り消せます。

**ネットワーク内で秘密投票はできますか？**
v1 では — できません：サードパーティアプリ用の識別子はアドレスと公開的に紐付いています。秘密投票は将来のバージョンでのみ可能になります。

**アプリが「単位は失効しました」と表示します。どういう意味ですか？**
サブスクリプション型ネットワーク（recurring）にいます：クォータは周期に紐付かれ、次の周期の境界の後は移転できません。これは罰金でも残高の喪失でもありません — 新しいクォータは新しい周期で届きます。余剰は、リソースを必要とする人に peer-redeem で渡すのがよいでしょう。

**参加にはいくらかかりますか？**
ネットワークは参加費を取りません。プラットフォームの運用コストはまったくありません — サーバーは存在しないのです。送金の手数料はバーンされ、誰のものにもなりません。

## 用語集

| 用語 | 意味 |
|------|------|
| **ウォレット** | 参加者のアカウント：アドレス + 署名済みレコードのチェーン + 残高。端末に一つ。 |
| **台帳** | ネットワークの全トランザクションの公開ジャーナル。各ノードが保管し検証します。 |
| **ジェネシス** | ネットワークの起動パッケージ：パラメータ、マニフェスト、シードサークル。 |
| **プロトコルバージョン（protocolVersion）** | ネットワーク規則のバージョン番号（現在 — 3）。すべてのトランザクションとチェックポイントに記録されます。アプリとネットワークはプロトコルバージョンで一致しなければならず、別バージョンのビルドはネットワークに受け入れられません。 |
| **マニフェスト** | ネットワーク規則の公開された記述。そのハッシュはジェネシスに固定されます。 |
| **シードサークル** | ジェネシスからの最初の参加者で、一時的な特権を持ちます。特権は自己消滅します（seed_sunset：活動ウォレット 100 個または 24 エポック）。 |
| **保証（vouch）** | 現役参加者が新人のためにする署名済みの保証。三つでウォレットがアクティベートされます。 |
| **保証枠** | 保証人の限られた枠。被保証人が 3 周期の発行を終えるか、90 日後に解放されます。 |
| **発行チャレンジ** | 現在の周期のスロットでの計算タスク（PoW）。事前に計算可能。ウィンドウ ±48 時間は各周期で利用可能で、その状態は発行画面が表示します。欠かしは蓄積ウィンドウ（6 周期）の範囲内で補償されます。 |
| **エポック** | ネットワーク時間の区間（デフォルト 24 時間）。エポックの境界でチェックポイントが置かれます。 |
| **チェックポイント** | 参加者のしきい値によって署名されたネットワーク状態のスナップショット。ファイナリティと軽量ノードの保護を与えます。 |
| **ファイナリティ** | その後はトランザクションをロールバックできない瞬間。 |
| **モラトリアム** | 登録後の期間（デフォルト 14 日）。送金の送信ができない期間です。 |
| **デマレージ** | 最低限を超える保管への小さな月次パーセント。引き落とされた分はバーンされます。 |
| **おとり** | 脅迫 PIN が開くモード：もっともらしいインターフェースと少額の残高、実際の操作はなし。 |
| **ガーディアン** | 電話の紛失時にマイグレーションを確認するために指名された参加者。 |
| **マイグレーション** | ガーディアン経由での新しい端末へのウォレット移転。14 日間の遅延。 |
| **ガーディアンの交代** | 個人ガーディアン（最大 3 人）の、その同意による再選出。48 時間のウィンドウ、ウォレットの生存期間中に発効する交代は 150 回まで。 |
| **Flagged** | 証明された違反（二重署名）の公開マーク。 |
| **Bluetooth 決済** | 署名済みトランザクションの Bluetooth 経由の受け渡し。ネットワークの確認後にのみ支払いになります。 |
| **ネットワークプロファイル** | パラメータの集合：単位、発行、移転、流出、アクセスなど。 |
| **Eq-ハッシュ（`Eq-<hash8>`）** | ネットワークの短いラベル（識別子の最初の 8 文字）。アプリ名とオンボーディングに表示され、正しいネットワークがインストールされているかの確認に使われます。 |
| **Recurring（サブスクリプション型ネットワーク）** | サブスクリプション型リソースのネットワーク：周期ごとの等しいクォータ、未使用分は周期の境界で失効。 |
| **Peer-redeem** | recurring ネットワークでの参加者 → 参加者、または参加者 → 提供者の送金：クォータの余剰はリソースを必要とする人へ流れます（現在のアプリのインターフェースでは未実装）。 |
| **クォータの失効** | 前周期の単位は、次の周期の境界の後は移転できなくなります。残高と履歴は保持されます。 |
