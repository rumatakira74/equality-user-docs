# 4. 所有者のセキュリティ

## PIN と生体認証：何が何のためか

| 操作 | 確認手段 |
|------|----------|
| アプリへのログイン | 指紋**または** PIN |
| 送金、発行、マイグレーションの開始 | **明示的な PIN 入力のみ** |
| ガーディアンの交代（公開、取り消し） | **明示的な PIN 入力のみ** |
| 操作内での鍵のアンロック | PIN の後の生体認証 — 「アンロック」のみ |

なぜそうなのか：指紋は**物理的に強制できます** — 他人の指をセンサーに力ずくで押し付けることは可能です。PIN は不可能です。だからこそ、損害を与えうるすべての操作はまさに PIN を要求し、PIN 入力の各画面はおとりモード（下記）への入り口点でもあります。

指紋によるログインは、インターフェースのアンロックの利便性に過ぎません。脅迫 PIN が有効な場合は完全に無効化されます。

## 脅迫 PIN とおとりモード

脅威：アプリを開けたり単位を送らされたりするよう強制されること。

設定時に二つの PIN を設定します：**通常**と**脅迫**。脅迫 PIN は**おとりモード**を開きます：

- インターフェースはまったく同じに見えますが、もっともらしい**少額の残高**と履歴が表示されます（ゼロを表示することはできません — 現役のウォレットには定期的に発行が届くので、ゼロ残高は不審です）；
- おとりからの「送金」は、もっともらしい「確認待ち」やネットワークエラーで終わります — 実際のトランザクションは公開されません；
- 本物のウォレットはバックグラウンドで動作し続けます；
- 通知に金額は含まれません：アプリには操作の通知はありません。唯一のシステム通知はノードのフォアグラウンドサービスのもの（「トラストネットワークのノードが動作中」）で、金額もアドレスもありません；
- おとりでは「ガーディアンの交代」がもっともらしく「実行」されますが、実際のガーディアンのリストには触れません。

二つの PIN は**区別できません**：同じオープン時間、同じインターフェース、同じ試行回数制限。脅迫 PIN は**どの** PIN 入力画面にも適用されます — 送金、発行、設定変更。

**隠せるが、ゼロにはできない：** 残高はネットワークの公開状態であり、鍵は削除されません。ローカルデータベースはシステムの正規の手段で削除できます — ネットワークとの照合時に復元されます。

## 遅延する大口送金 — 第二層

しきい値を超える送金（デフォルトで 3000 単位）は **48 時間**後に実行されます。実行前ならいつでもキャンセルできます。強制者は「送金済み」を受け取るのであって単位ではありません。あなたは安全な場所に着き次第、それを取り消します。遅延は固定で、無効化できません。

## 保護がしないこと（正直に読んでください）

- **公開台帳。** あなたが支払った人、または受け取った人はあなたのアドレスを知っています。履歴は公開で、残高はネットワークの状態から導出できます（アプリの台帳はアドレス、ステータス、年齢を表示します。残高 — ウォレット上とチェックポイントの Merkle 証明で）。おとりは検証されます：その中のアドレスはネットワーク上の実際のものと一致しません。
- **準備された攻撃者に対しておとりは保証されません。** それは迅速な強制と強盗に対して機能します。
- **解錠された電話の盗難に対しては**「操作ごとの署名」が保護します：電話を手に持っているだけで単位を使うことは不可能です。
- **電話の紛失に対しては** — ガーディアンとマイグレーション（[復旧](03-operations.md#アクセスの復旧)セクション）。ガーディアンがいなければ資金は失われます。
- **あなたの PIN を知る泥棒は**、14 日間のウィンドウ内でマイグレーションを取り消せます — v1 の既知の制限です。取り消しの権利は古い鍵に属します。緩和策 — 公共ガーディアンとマイグレーションの再開始。

## 安全な設定のチェックリスト

1. 初回起動時に PIN と脅迫 PIN を設定してください。
2. ガーディアンを指名してください（個人 3 人中 2 人、または公共 5 人中 3 人）— すぐに、ウォレット作成時に。
3. リカバリーカードを埋めてください（[「復旧」セクション](03-operations.md#リカバリーカード--事前に記入してください)）：ウォレットのアドレス、ガーディアンのアドレス、ネットワークの名前 — 記録して電話の外に保管してください。マイグレーションのデータ（nonce、ガーディアンの署名）は誰にも渡さず、公開もしないでください。
4. 自分の PIN は誰にも言わないでください。脅迫 PIN はなおさらです（その存在を知られてはいけません）。
5. 忘れないでください：システムに新しい指紋を追加すると鍵が無効化されます — これは差し替えに対する保護ですが、アクセスを失うあなたのリスクでもあります。
6. 大きな金額を「念のため」保有しないでください — 通貨ネットワークのデマレージはまさに貯蓄を罰します。
